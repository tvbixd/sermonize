How It Works

From sermon to structured notes in minutes

1

Tap & Record

Hit the mic button and let it run. Pause and resume as needed — the app produces a single seamless recording with a live timer.

2

AI Transcribes

Your recording is sent to Groq's Whisper v3 Turbo for fast, accurate transcription. You see the transcript build in real time as you record.

3

Outline Generated

Llama 3.3 70B reads the full transcript and returns a structured outline: title, theme, summary, main points with sub-points, and scripture references.

4

Scriptures Linked

Every Bible reference is detected and looked up automatically. The full verse text appears alongside each reference in your chosen translation.

Features

Everything you need, nothing you don't

Pause & Resume

Not a continuous stream? No problem. Pause during breaks, announcements, or worship — resume seamlessly into the same recording.

Live Transcription

See words appear on screen as the sermon is preached. The AI builds a live outline that updates every few minutes while you record.

8 Bible Translations

WEB, KJV, BBE, OEB, Almeida (Portuguese), Romanian, Cherokee, and Clementine Vulgate. Pick your preferred version in Settings.

Full Edit Mode

Edit every part of the generated outline — title, theme, points, sub-points. Add or remove points and scripture references as you see fit.

Folders & Organization

Create custom folders with color labels. Move sermons between folders, pin favorites to the top, and soft-delete with a Recently Deleted folder.

Export & Share

Export any sermon as a clean Markdown file via the system share sheet. Send to Notes, email, or any app on your phone.

Get Started

Up and running in 2 minutes

1

Clone & install

git clone https://github.com/tvbixd/sermonize.git
cd sermonize && npm install

2

Start the dev server

npx expo start — scan the QR code with Expo Go on your phone.

3

Add your Groq API key

Open Settings in the app, paste your free key from console.groq.com. That's it — start recording.
